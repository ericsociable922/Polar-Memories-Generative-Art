Designers and artists use these patterns to create layouts for t-shirts and digital apparel. The project combines creative coding with modern fashion design.

## 🎨 How to Use the Art

The application interface consists of simple controls to manage the animations:

* Click the Spacebar to cycle through the six different hexagon patterns.
* Move your mouse to change the rotation of the geometric shapes.
* Use the 'S' key to save a high-resolution snapshot of the current pattern. The app saves these files in the "Exports" folder within your installation directory.
* Press the 'F' key to toggle full-screen mode.
* Press the Escape key to close the application at any time.

## 🖼 Designing with Patterns

Each artwork features a transparent background option. This makes placing these designs on shirts or digital assets easy. You can import the exported screenshots into design software like Photoshop, Canva, or Illustrator. The geometric nature of the patterns allows for seamless tiling across fabrics.

## ⚙️ Troubleshooting

If you encounter issues, check these common items:

* Graphics Drivers: Make sure your computer uses the latest drivers for your display card. Visit the website of your computer manufacturer for updates.
* Permissions: If the app fails to save files, ensure you have write access to the folder where you installed the program.
* Antivirus: Some security software blocks new programs. If the app does not launch, check your antivirus quarantine list to ensure the file remains safe to run.
* Resolution: If the window looks too small or too large, press Alt+Enter to adjust the window size toggle.
